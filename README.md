# 五子棋 (Gomoku)

一个基于 HTML5 Canvas 的网页版五子棋游戏。

## 功能特性

- **双人对战** — 两名玩家轮流落子
- **人机对战** — 与 AI 对手进行游戏
- **悔棋** — 撤销上一步操作
- **胜负判定** — 自动检测五子连珠并高亮显示
- **计分板** — 记录双方胜负次数

## 技术栈

- HTML5 Canvas — 棋盘绘制与渲染
- CSS3 — 界面样式与动画
- JavaScript — 游戏逻辑与 AI 算法

## 快速开始

直接在浏览器中打开 `gomoku.html` 即可开始游戏，无需任何构建步骤。

```bash
# 方式一：直接打开
open gomoku.html

# 方式二：启动本地服务器
python3 -m http.server 8080
# 然后访问 http://localhost:8080/gomoku.html
```

## AI 算法

AI 使用启发式评估函数，通过以下方式选择最佳落子位置：

- **棋型评分** — 对活四、冲四、活三、眠三等棋型进行加权评分
- **攻防兼顾** — 同时评估己方进攻价值和对手威胁程度
- **中心偏好** — 优先选择靠近棋盘中心的位置
